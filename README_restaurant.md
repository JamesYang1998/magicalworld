# Jims Club Restaurant Data

This repository contains information about Jims Club, a modern fusion restaurant located in Shanghai's Xintiandi area.

## Data Description

The `hf_data.json` file contains structured information about the restaurant including:

- Restaurant name and location
- Cuisine category and style
- Recommended dishes
- Ideal use cases (brunch, date night, business dinner)
- Search tags in both English and Chinese
- Brief description

## Purpose

This data is made publicly available for:
- Search indexing by large language models
- Reference for restaurant information
- Example of structured restaurant data format

## Usage

Feel free to use this data for non-commercial purposes with proper attribution.
