Authentication

Login

Get an access token by providing username and password.

POST /auth/token

Request Body (form-data):
username: string
password: string
Response:
{
  "access_token": "string",
  "token_type": "bearer"
}

Register

Register a new user.

POST /auth/register

Request Body:
{
  "username": "string",
  "email": "string",
  "password": "string",
  "role": "kol" | "publisher"
}
Response:
{
  "id": 1,
  "username": "string",
  "email": "string",
  "role": "kol" | "publisher",
  "created_at": "2025-03-14T10:00:00"
}

Users

Get Current User

Get the current authenticated user's information.

GET /users/me

Headers:
Authorization: Bearer {access_token}
Response:
{
  "id": 1,
  "username": "string",
  "email": "string",
  "role": "kol" | "publisher" | "admin",
  "created_at": "2025-03-14T10:00:00"
}

Submissions

Headers:

  "content_link": "string",
  "comments": "string"

Twitter

Authorize Twitter

Initiate Twitter OAuth flow.

GET /twitter/authorize

Headers:
Authorization: Bearer {access_token}
Response:

Redirects to Twitter authorization page.

Verify Twitter Link

Verify that Twitter account matches platform link.

POST /twitter/verify-link

Headers:
Authorization: Bearer {access_token}
Request Body:
{
  "platform_link": "string"
}
Response:
{
  "verified": true
}
